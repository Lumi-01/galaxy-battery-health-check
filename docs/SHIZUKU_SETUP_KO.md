# Shizuku 설치 및 연결

처음 한 번 연결하면 **배터리 상태 확인** 버튼으로 상세 정보를 조회할 수 있습니다. 루팅과 PC는 필요하지 않습니다. 아래는 Galaxy S25의 무선 디버깅 방식이며, 베타 버전에서는 메뉴 이름이 다를 수 있습니다.

## 1. 설치

[Shizuku 공식 다운로드](https://shizuku.rikka.app/download/)에서 Google Play 또는 GitHub Release로 이동해 설치하세요. 갤럭시 배터리 앱은 **[앱 설치 파일 다운로드](https://raw.githubusercontent.com/Lumi-01/galaxy-battery-health-check/main/dist/galaxy-battery-0.5.0.apk)**를 눌러 받을 수 있습니다. 휴대폰에서 다운로드한 APK를 열어 설치하세요.

## 2. 개발자 옵션 열기

휴대폰 **설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호**를 7번 누르고, 요청되면 잠금 인증을 합니다. 설정 첫 화면 아래에 **개발자 옵션**이 생깁니다.

## 3. 무선 디버깅으로 페어링

1. Wi-Fi에 연결합니다.
2. **설정 → 개발자 옵션**에서 USB 디버깅과 **무선 디버깅**을 켭니다.
3. Shizuku에서 **무선 디버깅으로 시작 → 페어링**을 누릅니다. 알림이 필요하면 허용합니다.
4. 설정의 **무선 디버깅 → 페어링 코드로 기기 페어링**을 엽니다.
5. 표시된 코드를 Shizuku의 페어링 알림에 입력합니다. 코드 창은 입력할 때까지 유지하세요.
6. 페어링 완료 후 Shizuku로 돌아와 **시작**을 누릅니다. 실행 중 표시를 확인합니다.

## 4. 배터리 앱 연결

**배터리 상태 → 배터리 상태 확인 → Shizuku 권한 허용** 순서로 진행하세요. 다음부터는 같은 버튼으로 조회합니다.

폰을 재부팅하면 Shizuku를 다시 시작하세요. 기존 페어링이 남아 있으면 코드를 다시 입력할 필요는 없습니다. 시작이 안 되면 무선 디버깅을 껐다 켜고 재시도합니다. 자세한 동작은 [Shizuku 공식 설명서](https://shizuku.rikka.app/guide/setup/)를 참고하세요.

## 문제가 생기면

| 상황 | 확인할 내용 |
|---|---|
| 페어링 알림이 안 보임 | Shizuku 알림 권한과 백그라운드 실행 상태를 확인합니다. |
| 연결했는데 앱 권한이 없음 | Shizuku의 승인된 앱 목록에서 **배터리 상태**를 허용합니다. |
| 연결됐지만 값이 없음 | 펌웨어가 필드를 제공하지 않을 수 있습니다. 앱의 **로그 불러오기**를 사용합니다. |
| 개발자 옵션이 조직 정책으로 제한됨 | 기기 관리자에게 문의합니다. |

## 로그로 확인하기

삼성 전화에서 `*#9900#` → **Run dumpstate/logcat** → **Copy to sdcard**를 실행한 뒤, 앱의 **로그 불러오기**에서 새 dumpstate 파일을 선택합니다. 파일이 안 보이면 삼성 **내 파일**에서 Download 폴더로 복사하세요. 메뉴와 저장 경로는 펌웨어에 따라 다릅니다.

문제 분석이 필요하면 **측정 근거 · 결과 공유 → 복사**로 배터리 결과만 전달하면 됩니다. 전체 덤프는 필요하지 않습니다. Shizuku에 연결됐다는 사실만으로 삼성의 상세 배터리 필드 제공까지 보장되지는 않습니다.
